# KasKu - Aplikasi Manajemen Keuangan Pribadi

Aplikasi keuangan pribadi modern dengan fitur:
- Tambah/Edit/Hapus Transaksi
- Kategori Custom
- Grafik & Laporan Bulanan
- Export CSV & PDF
- Backup Data

## Fitur Utama
- Income vs Expense tracking
- Visualisasi grafik
- Export laporan
- UI Material 3

## Penggunaan
\`\`\`bash
flutter pub get
flutter run
\`\`\`
